# Wahidah social media

Finished pictures and videos posted by Wahidah (https://wahidah.app) on social media.

This repository only delivers those finished files over the web. It holds nothing else: no source
code, no original photographs, no settings.

Background photographs are from Pixabay contributors, used under the Pixabay Content License, as part
of Wahidah's own designs. Quran text is drawn in the King Fahd Glorious Quran Printing Complex font;
the English is Marmaduke Pickthall's translation (1930).
